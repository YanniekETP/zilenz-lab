# Zilenz Lab

Afzonderlijke, statische testwebshop. Geen koppeling met zilenz.nl, geen klantgegevens, bestellingen of echte betalingen.

## Publicatie
In GitHub: Settings > Pages > Build and deployment > Source: Deploy from a branch > Branch: main / (root) > Save.

Verwachte URL na succesvolle publicatie: https://yannieketp.github.io/zilenz-lab/

## Ontwikkeling
Wijzigingen aan `index.html` op de `main` branch worden na het instellen van GitHub Pages opnieuw gepubliceerd. De inhoud is een testprototype, geen WordPress of WooCommerce.
